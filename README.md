# U.S-Healthcare-Claim-Dashboard | Power-BI

## Project Overview:
This Power BI dashboard analyzes U.S. healthcare claims data to monitor claim performance, approval trends, denial patterns, and insurance provider contribution.  

The project focuses on transforming raw healthcare data into actionable insights that can help healthcare organizations improve operational efficiency and optimize claim management processes.

## Business Problem:
Healthcare organizations process a large volume of insurance claims daily. Inefficient claim handling, high denial rates, and pending claims can impact operational performance and revenue flow.

## This dashboard was built to:
- Track overall claim performance
- Identify departments with high denial rates
- Analyze insurer contribution and claim amounts
- Monitor approval efficiency
- Support data-driven decision-making

## Tools & Technologies Used:
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Key KPIs:
| KPI | Value |
|------|------|
| Total Claims | 500 |
| Total Claim Amount | $3K |
| Approved Amount | $2K |
| Approval Rate | 65% |
| Denial Count | 187 |

## Dashboard Features:
- Interactive KPI Cards
- Claim Status Analysis
- Year-wise Claims Matrix
- Insurance Provider Analysis
- Department-wise Denial Tracking
- Insurance-wise Claim Amount Comparison
- Dynamic Filtering Panel

## Key Insights:
- BCBS recorded the highest overall claim contribution among all insurance providers.
- Pain Management department showed the highest denial volume, indicating potential operational inefficiencies.
- UnitedHealthcare and Humana experienced comparatively higher denial counts.
- The overall approval rate of 65% suggests moderate claim processing efficiency.
- A considerable number of pending claims indicates opportunities to improve turnaround time.

## Business Impact:
This dashboard enables stakeholders to-
- Identify high-risk denial areas
- Monitor insurer performance
- Improve claim approval efficiency
- Reduce operational bottlenecks
- Enhance healthcare decision-making through analytics
